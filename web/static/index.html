1. Retrieval Scoring & Mathematical Caps
Retrieval Mechanics

In Permission-Aware RAG, documents are retrieved via two complementary modes: Dense Semantic Vector search and Hybrid Reciprocal Rank Fusion (RRF). Understanding their score bounds is vital for interpreting system relevance:

FAISS Dense Similarity Cap: 1.000
cos(θ) = (u · v) / (||u|| ||v||)
Measures latent angular proximity in the 384-dimensional embedding space. A score near 1.0 indicates near-identical semantic intent even with non-overlapping vocabulary.
Hybrid RRF Fusion Cap: ~0.0328
RRF(d) = ∑ 1 / (60 + rankm(d))
Fuses FAISS semantic ranking with BM25 keyword frequency. Because it sums reciprocal ranks (k=60), rank 1 in both yields 1/61 + 1/61 ≈ 0.0328. A score >0.025 indicates consensus.

4. Academic Evaluation Metrics
HCI Benchmarking

System performance is audited against standard NLP and information security criteria:

Exact Match (EM)
Binary 1.0 or 0.0 indicating whether normalized predicted string exactly matches the ground truth answer.
F1 Score
Harmonic mean of token precision and recall (2 × P × R / (P + R)). Handles syntactic variants.
Permission Coverage (%)
The proportion of cloud buckets in the benchmark repository authorized under the active IAM policy.
Security Match
Verification that no document outside the caller's IAM clearance is ever injected into the prompt context.
